# 🧠 MetricMind

AI-Powered Business Intelligence Dashboard built using **Python, Streamlit, FastAPI, Plotly and Pandas**.

---

## 🚀 Features

- 📊 Interactive Dashboard
- 🤖 AI Assistant
- 📈 Sales Analytics
- 🌍 Region & Category Filters
- 📥 Export Filtered Data
- 📊 Business Insights
- ⚡ FastAPI Backend
- 🎨 Enterprise Dark Theme

## ▶️ Installation

```bash
git clone https://github.com/yourusername/MetricMind.git

cd MetricMind

pip install -r requirements.txt
```

---

## ▶️ Run Backend

```bash
uvicorn backend.app:app --reload
```

---

## ▶️ Run Frontend

```bash
streamlit run frontend/app.py
```
